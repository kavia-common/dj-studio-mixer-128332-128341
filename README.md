# dj-studio-mixer-128332-128341

This workspace contains the Android app in `music_dj_creator_frontend/`.

Build locally or in CI using the helper script:

- Linux/macOS:
  ./build-android.sh

The script runs the app Gradle wrapper located at:
music_dj_creator_frontend/gradlew

For CI systems that expect a single entrypoint, use:
./run-ci.sh
